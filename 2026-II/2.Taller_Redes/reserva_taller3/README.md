# Reserva para el Taller 3

El primer acto que tuvo el Taller 2 («De una escritura a una red»). Se sacó para que el
Taller 2 quedara todo en Florencia, y se guarda aquí para abrir el Taller 3 (Aprile en
lenguaje de redes vía las transacciones de la Notaría 2).

- `notaria_escrituras.ts` — seis escrituras reales (1938 y 1943) del componente de
  Francisco Caicedo B., con posiciones para dibujarlas y la respuesta de cada una. Incluye
  la trampa: la sociedad Caicedo Hermanos (1938), que la base registra como venta pero en la
  que no pasa tierra.
- `Acto1Escrituras.tsx` — el componente: el estudiante marca quién entrega y quién recibe
  y la red dirigida se dibuja sola. Depende de `Red.tsx` y `ui.tsx` del Taller 2.

La lección que carga: Caicedo tiene el grado total más alto (4) pero 3 son de salida;
reparte tierra, no la acumula. Es la entrada natural al grado de entrada = acumulación.
El lote de El Follce recorre un camino Hoyos → Caicedo → Fernando Caicedo (jun–oct 1943).

**Ya se usó** (oct-2026): es el Acto 2 de `3.Taller_Relatos/taller-relatos/`.
